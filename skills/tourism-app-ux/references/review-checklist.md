# 完成前チェックリスト

「できました」と言う前に、スマホ幅（375px）のブラウザで実際に操作しながら通す。
読むだけで済ませない。1 つでも当てはまらなければ直してから報告する。直せなかった項目・確かめられなかった項目は、報告に書く。

## 通し
- [ ] 最初の場面から最後の場面まで、止まらずに 1 回通せる
- [ ] 初めて開いた状態（データなし）で、何をすればいいか分かる
- [ ] 途中でやめて開き直しても、続きから進める

## 各画面
- [ ] 一番上に「いまやること」があり、文 1 つ・主ボタン 1 つ
- [ ] 塗りつぶしのボタンは画面に 1 つだけ
- [ ] その画面でいちばんやる操作に、スクロールなしで届く（任意の入力が主ボタンより上にない）
- [ ] 同じ情報が 1 画面に 2 回出ていない
- [ ] 固定のバーやポップアップが、一覧の最後の行・選んだピン・ほかの操作を隠していない
- [ ] 強調色が、開いた瞬間に目に入る大きさで使われている（小さな点だけになっていない）。多くても 3 箇所
- [ ] 説明文なしで意味が通る（説明文を足して済ませていない）
- [ ] 押せるものは 48px 以上、隣と近すぎない
- [ ] 戻るボタンの行き先が、その作業の起点になっている

## 操作
- [ ] 長押し・ダブルタップ・スワイプだけの操作がない（スワイプには同じ働きのボタンがある）
- [ ] 取り消せない操作は「ボタン → 確認」
- [ ] 操作の結果が、押した場所のすぐ下か、その場のポップアップに出る
- [ ] 同じ種類の操作（撮影など）は、配置と流れがそろっている
- [ ] ふり返りの画面に、状態を変えるボタンがない
- [ ] 連続で素早く操作しても、表示が崩れない・二重に登録されない

## 見た目
- [ ] 設計メモの先頭に、テーマ色・強調色・背景・字の 4 色が色名と値で書いてある
- [ ] テーマ色と強調色を、題材に実際にあるものから選んだ理由が 1 行で書いてある（Skill や見本の組み合わせをそのまま使っていない）
- [ ] テーマ色が黒や灰色に見えない。テーマ色と強調色が互いを引き立てている
- [ ] 画面を並べて見たとき、のっぺりしていない（強調色と色つきの絵が効いている）
- [ ] 部品の色は 4 色とテーマ色の濃淡だけ（例外は意味が色そのもののもの）
- [ ] 場所の絵・地図は色つきで、場所ごとに描き分けてある（記号 1 つ・単色で済ませていない）
- [ ] 見本（ひとめぐり）の色ちがいに見えない。題材にしかない見せ方が 1 つある
- [ ] 色の値を部品に直接書いていない（変数を参照している）
- [ ] 見出しは明朝、本文はゴシック。外部フォントを読み込んでいない
- [ ] 文字の大きさを最大にしても、はみ出し・重なりがない
- [ ] 高コントラストの設定で、すべての文字と枠が見える
- [ ] 常に動き続けるものがない。動きを減らす設定で動きが止まる
- [ ] 動く部品のまわり（下タブなど）が揺れていない
- [ ] 画像が読めないとき、枠と代わりの文字が出る

## 仕掛け
- [ ] 選んだ時点で、数と所要時間の目安が出る
- [ ] 集めるものは空き枠ごと見え、「あと N つ」が分かる
- [ ] 場所を、名前を読まなくても見分けられる（一文字・紋・絵）

## 言葉
- [ ] ボタンは動詞、利用者の言葉
- [ ] 内部の呼び名・ID・英語の項目名が画面に出ていない
- [ ] 人の名前が自然な呼び方になっている
- [ ] 名前を変えたものの旧名が、画面・既存データ・画像に残っていない

## 使えないとき
- [ ] カメラ・位置情報・共有が使えなくても、最後まで進める
- [ ] データが空の画面に、一言と次の操作がある
- [ ] 通信エラーで画面が真っ白にならない
- [ ] 端末への保存ができない環境でも動く

## 作らないもの
- [ ] 順位・星・点数による格付けになる表示がない（集計画面も含めて見る）
- [ ] 少人数（3 件未満）の集計を出していない
- [ ] お金に関わる内部の数字が、利用者の画面に出ていない

## 運営の画面（ある場合）
- [ ] 開くとホームで、先頭が「次の一手」
- [ ] スマホ幅で 1 列になり、表が横にはみ出さない
- [ ] 編集した内容が、利用者の画面に反映され、再起動しても残る
- [ ] 送っていない項目が空で上書きされない
- [ ] おかしな入力（範囲外の数字、ありえない時刻）を受け付けない

## デモ（ある場合）
- [ ] デモ用の設定なしで起動すると、デモ用の API と画面が使えない
- [ ] 初期化で、主人公が作ったものがすべて消え、最初から通し直せる
- [ ] 場面の切替を行き来しても、表示の順番や内容が食い違わない
- [ ] 見せたい演出が、運に左右されずに出る

## 仕上げ
- [ ] テストとビルドが通る（件数を報告に書く）
- [ ] 借りた素材の出典がまとまっている
- [ ] 判断の記録と進捗が最新
- [ ] 確かめられなかったこと（実機のカメラ、実際の印刷など）を報告に書いた
