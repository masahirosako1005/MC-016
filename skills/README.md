# tourism-app-ux（観光アプリの UI/UX の型）

観光・おでかけ・地域・店舗向けの、一般の人がスマホで使う Web アプリを、細かい UI の指示なしで高い完成度に仕上げるための Claude 用 Skill です。
観光アプリ「ひとめぐり」を 10 回のフィードバックで磨いた経験から作りました。

- 版: 0.3（2026-11-10）
- 状態: 形式の検証は済み。同じお題（温泉街の湯めぐりアプリ）で、Skill なし・版 0.1・版 0.2 を各 1 回比べ、その結果を反映したのが版 0.3 です。版 0.3 での試験と、別のお題での試験はまだです。

### 変更点

- 0.3: 題材別の配色の例示をやめ、題材に実際にあるものから色を拾う手順に変更（0.2 は例示した組み合わせがそのまま使われた）。同じ情報を 1 画面に 2 回出さない、固定の部品で中身を隠さない、任意の入力を主ボタンより上に置かない、を追加。
- 0.2: 最初に配色 4 色（テーマ色・強調色・背景・字）を決める手順を追加。強調色を「どの画面でも目に入る大きさで使う」に変更（0.1 は小さな点だけになり、のっぺりした）。場所の絵・地図は色の決まりの外とし、場所ごとに描き分ける。所要時間の目安、空き枠と「あと N つ」、場所を見分ける印を追加。見本の色ちがいにならないよう注意を追加。
- 0.1: 初版。

## 入れ方

### Claude Code（デスクトップアプリの Code タブ、CLI、IDE 拡張）

`tourism-app-ux` フォルダを、次のどちらかにコピーします。

| 置き場所 | 効く範囲 |
|---|---|
| `~/.claude/skills/tourism-app-ux/`（Windows は `C:\Users\<ユーザー名>\.claude\skills\tourism-app-ux\`） | 自分のすべてのプロジェクト |
| `<プロジェクト>/.claude/skills/tourism-app-ux/` | そのプロジェクトだけ（Git に入れればチーム全員に効く） |

コピーしたら、新しいセッションを開始します（開いているセッションには反映されないことがあります）。

### claude.ai（チャット版・デスクトップアプリのチャット）

設定画面の Skills（機能）から `tourism-app-ux.skill` をアップロードします。
組織の設定で Skill の追加が止められている場合は、管理者に依頼してください。

## 使い方

入れたあとは、ふつうに頼むだけです。

- 「○○温泉の観光客向けスマホアプリを作って」
- 「商店街のクーポンアプリの画面を作り直して」

Claude が自動でこの Skill を読みます。読んでいないようなら「tourism-app-ux を使って」と添えてください。

見本の色（藍と山吹）は一例です。題材に合わせて Claude が色を決め直します。指定したい場合は「主色は深緑、差し色は朱で」のように伝えてください。

## 気づいたことの集め方

使ってみて、次のどれかがあったら記録してください。Skill を直す材料になります。

1. Skill を使ったのに、利用者から指摘されたこと（Skill に書いてあったか、なかったかも）
2. Skill が題材に合わない型を押しつけたこと
3. 書いてあるが、なくても同じ結果になりそうなこと

記録する内容: 案件名、起きたこと、画面の写真、Skill のどのファイルに関係するか。

## 直すときの約束

- 直す担当を決め、全員が直接書き換えない
- 2 回以上起きたことだけ `SKILL.md` に入れる。1 回きりは `lessons-from-feedback.md` に
- 足したら、同じ分だけ削る。`SKILL.md` は 1〜2 画面分を保つ
- 規則ではなく理由を書く
- 直したら版を上げ、この README の「版」と変更点を更新する
