# 構成: ひとめぐり便 — 場所めぐりから人めぐりへ

- キット: shiryo-slides（https://github.com/code4biz/shiryo-slides-kit）の full モードで設計
- テーマ: F（藍 × 山吹・追加テーマ。下記）/ 用途: 提案資料 / スタイル: visual（viz:high）/ 全 10 枚
- 発表時間: 6 分（スライド 約 3 分 40 秒 + デモ 約 2 分 20 秒）。台本は `docs/08_demo_scripts.md`
- 言いたいことを 1 文で: **人を再訪させるのは場所ではなく人。だから入口は場所のまま、出会いを記録して思い出と次の約束を残し、もう一度その人に会いに行く理由をつくる。**
- 開き方: `slides/hitomeguri-pitch.html` をダブルクリック → F11 で全画面。← → キーでめくる（`#7` のように URL 末尾に番号を付けるとその枚から開く）

## スライド 1: 表紙
- 役割: 何の提案か（場所めぐり → 人めぐり）
- レイアウト: 型 C ウォーターマーク（藍の全面 + 薄い HITOMEGURI）。山吹の短い罫を 1 本
- なぜこの形か: 主題を一語で言い切れる。アプリの藍をそのまま見せて、デモと地続きにする（型 G は硬すぎるので退けた）

## スライド 2: 再訪が続かない理由（SECTION 01）
- 役割: 課題。「一回行ったし、もう一回は行かなくてもいいかな」
- レイアウト: 壁（進行 × 障害）。景色・名物・スタンプ → 「達成して完了」の壁 → 向こう側に薄い「2 回目の旅」
- なぜこの形か: 満足しているのに先へ進めない、を絵にできる。左右対比（場所 vs 人）は 5 枚目で使うのでここでは退けた

## スライド 3: 北海道に通う理由（SECTION 02）
- 役割: 発表者自身の事実。観光で 10 回以上、この 2 年で 3 回。目的は「人に会いに行くこと」
- レイアウト: 特大数字 + 藍ブロック（結論）
- なぜこの形か: 数字が主役。箇条書きにすると「10 回」の重みが消える

## スライド 4: 一人の出会いから続く旅（SECTION 02）
- 役割: 出会いが旅の理由を生み続けた経過（友人とバーめぐり → 顔なじみ → その人に会いに → 大会の会場へ）
- レイアウト: 右上がりの階段（ladder）4 段
- なぜこの形か: 関係が深まるほど旅の理由が増える、を高さで示す。縦路線図は横に時間が流れる 8 枚目と紛れるので退けた

## スライド 5: 再訪を生むもの（SECTION 03）
- 役割: 気づき。人をもう一度呼ぶのは場所ではなく人
- レイアウト: 大きな一文 + 左右対比（場所 = ライト面 / 人 = 藍ブロック）。「人」に山吹の下線
- なぜこの形か: 対比は 2 項。カード 3 列にする内容がない

## スライド 6: 入口は場所のまま（SECTION 03）
- 役割: 最初から人を目当てにする旅行者は少ない。入口は場所でよく、その奥に人がいる（お城とボランティア解説員の経験）
- レイアウト: 入れ子（場所の箱の中に「そこにいる人」の箱）。地は強調面（--surface）
- なぜこの形か: 「場所の裏側に人がいる」を包含で示す。Before/After にすると 5 枚目と同じ体裁になるので退けた

## スライド 7: 人めぐりという提案（SECTION 04）
- 役割: 解決策。会う → 残す → また会いに行く、が回り続ける
- レイアウト: 3 段の矢印チェーン + 下に戻りの帯（HTML。線描画 SVG は使わない）
- なぜこの形か: 循環だが、三角ループ図は線と文字の干渉が出やすい。キットの推奨どおりピル + 戻りキャプションで代用

## スライド 8: 旅前から次の季節まで（SECTION 04）
- 役割: デモの地図。5 場面（10/17 旅前 → 10/24 旅中 → 19:00 その夜 → 11/23 30 日後 → 12/01 次の季節）
- レイアウト: 時間軸（線 + 点 + 日付）。後ろ 3 場面に「旅の後にも開く理由」の帯
- なぜこの形か: 時系列。幅を実時間比にすると「その夜」が潰れるので等間隔にした
- このあとデモ（`/#/present`）へ切り替える

## スライド 9: お店と地域に届くもの（SECTION 05）
- 役割: 旅人・お店の人・地域（DMO）それぞれに届くもの。格付け・ランキングは作らない
- レイアウト: 行組み（立場 | 届くもの）
- なぜこの形か: 3 者を並べるが、カード 3 列は 7 枚目と重なるので行で組んだ

## スライド 10: 締め・次のステップ
- 役割: 「一回行ったし」を「あの人にまた会いに」へ。まず場所をひとつ選び、そこにいる人に会ってみてください
- レイアウト: 藍の全面 + 大きな一文
- なぜこの形か: 2 枚目の引用を回収して終える

## テーマ F — 藍 × 山吹（このデッキ用の追加テーマ）

キットの 5 テーマに近いものが無いため、テーマ追加の手順（16 変数・面ルール・スケール 6 値・コントラスト実測）で定義した。色はアプリ本体の「藍染と和紙」に合わせている。

```css
:root{
  --bg:#fbfcfd; --surface:#f0f3f8; --ink:#1b2a44; --sub:#4f5d75; --dim:#76829a; --line:#d9dfe9;
  --accent:#3a5a92; --accent-deep:#24406e; --accent-tint:#e6ecf5;
  --spark:#e3a21a;            /* 山吹。面専用・文字色禁止・デッキ全体で 2 箇所まで */
  --ink-surface:#1b2a44; --on-dark:#fbfcfd; --accent-on-dark:#b9c8e4; --line-on-dark:#33466a;
  --radius:4px;
  --ff:"Yu Gothic UI","Yu Gothic","Hiragino Sans","Meiryo",sans-serif;
  --ff-serif:"Yu Mincho","YuMincho","Hiragino Mincho ProN","MS PMincho",serif;  /* 見出し */
  --ff-en:Cambria,"Times New Roman",serif;                                    /* 数字・ラベル */
}
```

- **Web フォントは使わない**（プロジェクトの約束: 外部 CDN・外部フォント禁止。会場がオフラインでも見た目が変わらない）。キットの「Google Fonts の link」は意図的に外した
- コントラスト実測: ink/bg 13.99、sub/bg 6.48、sub/surface 5.98、dim/bg 3.77（ラベル専用）、accent/bg 6.69、accent-deep/bg 10.05、ink/accent-tint 12.10、on-dark/ink-surface 13.99、accent-on-dark/ink-surface 8.52
- 面ルール: 全面ダーク 2 枚まで（表紙と締め）。藍ブロックは 1 枚に 1 個・デッキで 3 枚まで（現状 3・5 枚目）。山吹は 2 箇所（表紙の罫・5 枚目の下線）
- スケール: h1 56px/700、h2 30px/700、本文 16〜19px（最小 14.5px）、KI ラベル 11px

## 検査の記録
- preflight（core/rules.md §12 と提案資料の追加検査）: 禁止事項のヒットなし。残した例外は、装飾ラベル 11px（KI・ページ番号）と注記 12px、8 枚目の `repeat(5,1fr)`（カード grid ではなく時間軸）、6 枚目の surface + accent-tint（入れ子の 2 面で、並列カードではない）、8 枚目の図中ラベルの常体（「選ぶ。」など。幅の都合）
- 視覚検証: Playwright が未導入のため、キットの capture.js の代わりに Edge のヘッドレスで全 10 枚を 960×540 で撮影し、2 周（iter-0 → iter-1）全枚を目視。iter-0 で 4 枚目の見出し折り返しによるはみ出し、数字の書体（オールドスタイル数字）、投影には小さい文字を直した。DOM 幾何チェックは未実施（線描画 SVG を使っていないため対象なし）
