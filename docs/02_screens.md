# 02 画面

下タブは 5 つ: **計画／マップ／思い出／ひとめぐり帖／クーポン**。各タブの一番上に「いまやること」カード（主ボタン 1 つ）。初回起動時に 3 枚の使い方ガイド、さらに **画面ごとのチュートリアル（図解つき）** が初回に 1 度出る（ヘッダの「？」でいつでも再表示）。ヘッダは画面上部に固定（戻るボタンつき）。ボタンは 48px 以上、長押し操作は使わない。
デザイン: 藍染と和紙の手紙。藍 `#1b2a44`・紙 `#fbfcfd`・差し色 山吹 `#e3a21a`（1 画面 1 箇所）。見出しは明朝（Yu Mincho）、本文はゴシック（Yu Gothic UI）。状態色は藍の濃淡で表す。

| ルート | 画面 | 主な内容 |
|---|---|---|
| `#/plan` | 計画（旅前） | 「旅のプラン」一覧（新しい旅をつくる・終わった旅と行けなかった場所）→ 旅ごとに 3 ステップ。行けなかった場所は次の旅のカードの先頭。① **カードをスワイプ**（右=行く／左=行かない、下のボタンでも可）。カードは風景写真 + 紹介 + 「ここにいる人」。左上のタグ: 「前回行けなかった場所」または「**○に行った（M/D）→ △はどう？**」（別の季節にもう一度）。② **地図で整える**: 選んだ場所が山吹の番号ピンで並ぶ。ピンをタップで外す／戻す。③ **日を決める**: 日付 → 「この予定で決める」→ その日に会えそうな人（定休日で判定）・花になる種・使えるクーポン。**Google カレンダーに入れる**（テンプレート URL）と **カレンダー用ファイル（.ics）** |
| `#/place/:id` | 場所の画面 | 旅前: 紹介・アクセス・**行き方と連絡先**（住所・電話・営業・最寄り・Web・旅行者へのメモ。店が運営の窓で編集）・ここにいる人・「行きたい」・旅人の声。旅中は「住所・電話・行き方」を折りたたみで。旅中（営業中 or 会えた日）: **ここにいる人**（会えた → ほしまると AR フォト → 花の日は「約束を果たす」）、**レシートを撮る**（撮影 → AI-OCR 風の読み取り演出 → 店・金額を確認して登録）、**クーポンを使う**（確認 → 使用済み）。「マップにもどる」 |
| `#/people/:id` | 人の詳細 | 絵・役割・ひとこと・いる場所と営業時間・行き方と連絡先・季節の約束 4 つ・種／花・この場所のほしまる・旅人の声・この場所で撮った一枚 |
| `#/` | マップ（旅中） | 自作の星凪諸島の地形図 `img/map/hoshinagi_map.png`（文字なし。別セッションで Fantasy-Map-Generator から作成）を背景に、地区名・場所名・ピン・人・現在地を自前 SVG で重ねた地図。**ピンをタップするとポップアップ**（場所名・状態・営業・定休・住所・電話・いる人）が地図の上に出て、画面を移らずに確認できる。「この場所で 会えた・AR・レシート」で場所の画面へ。**山吹の番号ピン=きょう行く場所、チェック=会えた場所、青い点=現在地**（デモでは計画の次の場所の近く）。場所の点に人のアバター。タップで場所の画面へ。下に行く場所／ほかの場所の短い一覧 |
| `#/camera/person/:id` | AR フォト | カメラ映像（不可なら写真選択→その場所の風景写真）に **その場所の「ほしまる」**（透過 PNG、ドラッグ・大きさ・傾き）か、**フレーム**（★その場所だけの特別フレーム 1 種 + 共通 5 種: 藍の縁・星空・おもいで便・チェキ・ひょっこり。900×1200 の透過 PNG を重ねる）と日付の札を合成。フレームのときは左上に小さな日付札だけ。**シャッターは映像のすぐ下**（大きく 1 つ）、フレームはその下に横スクロールのチップで選ぶ。保存後は写真の画面 → 場所の画面にもどる |
| `#/photo/:id` | 写真 | ダウンロード・共有・印刷へ・場所の画面にもどる |
| `#/print/:id` | 印刷 | ハガキ判 100×148mm の印刷レイアウトと PNG 保存 |
| `#/memories` | 思い出 | 一覧: 「10/24 の思い出」「11/23 星凪諸島からの便り（30 日後）」「鈴木さんからの便り（お店から、クーポン付き）」が日付順。思い出の中身は **コルクボード**（AR フォト・会えた人・行った場所をポラロイド風に、日記は付箋）。一言日記 140 字。次の旅の提案 3 つ（写真と人つき）→ 行きたい。便りの中身: あの日の思い出（コルクボード）+ 「行きたい」と選んだ場所（写真）+ 次の季節まで N 週間 → 計画へ |
| `#/book` | ひとめぐり帖 | **会えた人 N / 8 人**と回数の帯の内訳（旧: 季節のスタンプ N / 32（人ごとに春夏秋冬の 4 つの**絵のスタンプ**: 春=桜・夏=太陽と波・秋=もみじ・冬=雪の結晶。会えた季節は藍のインクで押され（少し傾く）、回数を山吹の札で添える。4 つそろうと「一年めぐった」。花は「果たした約束」として小さく）、進み具合のバー。8 人のカード: 会えた人は色つき + 「会えた」スタンプ + 関係、まだの人はシルエットで「？？？」。これまでの旅、アルバム |
| `#/wallet` | クーポン | いまやること → クーポン（使えるお店のチップ）→ ポイントと抽選（確率表）→ レシート一覧。アイコンは紙チケット |
| `#/shop/:id` | 店ページ | 場所の写真・紹介・お店の人・ここで使えるクーポン（確認して使う） |
| `#/settings` | 設定 | 文字の大きさ・配色・やさしい日本語・使い方をもう一度見る |
| `#/admin` | 運営の窓 | スマホでも PC でも。立場（DMO／お店）は本番ではアカウント権限で決まる想定で、画面上部の切替はなし（デモは右下の ⚙ フローティング、または present の操作列）。 **下線つきの機能タブ**（選択中は太字 + 山吹の下線）→ 「運営の窓 › 地域（DMO） › ○○」の**いまの場所**と一言説明。立場ごとに機能を分ける: DMO = ホーム（次の一手・ダッシュボード）／イベント・来訪予定／指標・補填／還元率・商品・取り込み／レシート・履歴、お店 = ホーム（次の一手・来訪のようす）／来訪・イベント／お店の情報／旅行者への便り。720px 未満は 1 列。2 つの立場を切り替え。**地域（DMO）**: 観光消費額・来訪者数・会えた回数の月次グラフ、イベントのお知らせ（外部起因のイベントを登録して店へ）、指標、来訪予定、CSV 取り込み、還元率、商品、補填、履歴。**お店・施設**: 自分の店を選び、来訪のようす（地区平均・島平均との比較）、来訪予定と DMO からのイベント、**次の一手**（データから規則で組み立てた提案。ボタンで便りの下書き・編集欄・来訪予定に飛ぶ）、紹介・おすすめ・写真・**住所・電話・Web・最寄り・行き方・メモ・営業時間・定休日**の編集（旅行者の場所画面に反映）、旅行者への便り（**来訪回数=はじめまして／また会えたね／おなじみ と 種の状態=種なし／つぼみ／花 で宛先を絞り、届く人数を表示**。クーポン付き、会ったことのある人に届く）。DMO 側にも **次の一手**（季節の便りの準備・満足なのに再訪なし・地区の偏り・イベント未登録・前月比・来訪計画） |
| `#/present` | 発表用（DEMO_MODE=1） | 1280×720。帯は ⓪旅前／①旅中／②その夜／③30 日後／④次の季節／**⑤運営**（選択中は山吹の下線）。左は**つねにスマホ枠**（上に「場面・いまの画面名」、下に場面の説明。⑤では運営の窓をスマホ枠で見せ、「PC 幅で見る」で広げられる）。右は **16:9 のスライド（8 枚、← → キー）**を本体と同じ高さに収め、文字を大きく、下に進み具合のバー。操作列（前／次・本体の画面切替・抽選の固定・初期化）は下に 1 段 |
