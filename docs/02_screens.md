# 02 画面

下タブは 5 つ: **計画／マップ／思い出／ひとめぐり帖／クーポン**。各タブの一番上に「いまやること」カード（主ボタン 1 つ）。初回起動時に 3 枚の使い方ガイド、さらに **画面ごとのチュートリアル（図解つき）** が初回に 1 度出る（ヘッダの「？」でいつでも再表示）。ヘッダは画面上部に固定（戻るボタンつき）。ボタンは 48px 以上、長押し操作は使わない。
デザイン: 藍染と和紙の手紙。藍 `#1b2a44`・紙 `#fbfcfd`・差し色 山吹 `#e3a21a`（1 画面 1 箇所）。見出しは明朝（Yu Mincho）、本文はゴシック（Yu Gothic UI）。状態色は藍の濃淡で表す。

| ルート | 画面 | 主な内容 |
|---|---|---|
| `#/plan` | 計画（旅前） | 3 ステップ。① **カードをスワイプ**（右=行く／左=行かない、下のボタンでも可）。カードは風景写真 + 紹介 + 「ここにいる人」。② **地図で整える**: 選んだ場所が山吹の番号ピンで並ぶ。ピンをタップで外す／戻す。③ **日を決める**: 日付 → 「この予定で決める」→ その日に会えそうな人（定休日で判定）・花になる種・使えるクーポン。**Google カレンダーに入れる**（テンプレート URL）と **カレンダー用ファイル（.ics）** |
| `#/place/:id` | 場所の画面 | 旅前: 紹介・アクセス・ここにいる人・「行きたい」・旅人の声。旅中（営業中 or 会えた日）: **ここにいる人**（会えた → ほしまると AR フォト → 花の日は「約束を果たす」）、**レシートを撮る**（撮影 → AI-OCR 風の読み取り演出 → 店・金額を確認して登録）、**クーポンを使う**（確認 → 使用済み）。「マップにもどる」 |
| `#/people/:id` | 人の詳細 | 絵・役割・ひとこと・いる場所と営業時間・季節の約束 4 つ・種／花・この場所のほしまる・旅人の声・この場所で撮った一枚 |
| `#/` | マップ（旅中） | 地図アプリ風の島の地図（海・陸・緑地・砂浜・道路・航路・地名）。**山吹の番号ピン=きょう行く場所、チェック=会えた場所、青い点=現在地**（デモでは計画の次の場所の近く）。場所の点に人のアバター。タップで場所の画面へ。下に行く場所／ほかの場所の短い一覧 |
| `#/camera/person/:id` | AR フォト | カメラ映像（不可なら写真選択→その場所の風景写真）に **その場所の「ほしまる」**（場所の小物 + 季節の衣装）と日付・場所を合成。ドラッグ・大きさ・傾き。保存後は写真の画面 → 場所の画面にもどる |
| `#/photo/:id` | 写真 | ダウンロード・共有・印刷へ・場所の画面にもどる |
| `#/print/:id` | 印刷 | ハガキ判 100×148mm の印刷レイアウトと PNG 保存 |
| `#/memories` | 思い出 | 一覧: 「10/24 の思い出」と「11/23 星凪諸島からの便り（30 日後）」が日付順。思い出の中身は **コルクボード**（AR フォト・会えた人・行った場所をポラロイド風に、日記は付箋）。一言日記 140 字。次の旅の提案 3 つ（写真と人つき）→ 行きたい。便りの中身: あの日の思い出（コルクボード）+ 「行きたい」と選んだ場所（写真）+ 次の季節まで N 週間 → 計画へ |
| `#/book` | ひとめぐり帖 | **会えた人 N / 8 人**と咲いた花の数、進み具合のバー。8 人のカード: 会えた人は色つき + 「会えた」スタンプ + 関係、まだの人はシルエットで「？？？」。これまでの旅、アルバム |
| `#/wallet` | クーポン | いまやること → クーポン（使えるお店のチップ）→ ポイントと抽選（確率表）→ レシート一覧。アイコンは紙チケット |
| `#/shop/:id` | 店ページ | 場所の写真・紹介・お店の人・ここで使えるクーポン（確認して使う） |
| `#/settings` | 設定 | 文字の大きさ・配色・やさしい日本語・使い方をもう一度見る |
| `#/admin` | 運営の窓 | 指標、**来訪予定（日ごとの計画の数と行き先）**、CSV 取り込み、店の還元率（人名併記）、抽選の商品、補填、直近レシート、変更履歴 |
| `#/present` | 発表用（DEMO_MODE=1） | 1280×720。帯は ⓪旅前／①旅中／②その夜／③30 日後／④次の季節／**⑤運営**。左にスマホ枠の本体、右に **プレゼンのスライド（8 枚、← → キーで送れる）**。⑤では左が運営の窓に切り替わる |

花が咲く演出: 約束を果たすと全画面で花が開き、「ひとめぐり帖で見る」へ。
