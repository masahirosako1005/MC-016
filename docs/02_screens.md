# 02 画面

下タブは 4 つ（しらべる／きょう／おもいで／おさいふ）。ボタンは 48px 以上、1 画面で目立たせるボタンは 1 つ。設定（文字 3 段階・配色 2 種・やさしい日本語）は右上の歯車から。

| ルート | 画面 | 主な内容 |
|---|---|---|
| `#/explore` | しらべる（旅前） | つぎの旅の要約、自前 SVG 諸島マップ、キーワード検索、チップ（カテゴリ／季節／地区）、スポット 7 + 店 8 のカード、旅人の声（内部ダミー、件数・順位なし） |
| `#/place/:kind/:id` | 場所の詳細 | 紹介・アクセス・見ごろ、お店の人の季節の約束、この場所のお店、旅人の声、みんなの一枚、「つぎの旅に入れる」 |
| `#/plan` | つぎの旅 | 予定日、行く場所（はずす）、その季節に花になる種、その日に使えるクーポン |
| `#/` | きょう（旅中） | 日付・季節、計画の品目を先頭、会えそうな人の予報（会えそう／もうすぐ閉まる／まだ／閉店／定休）と理由、季節イベント、「会えた」→ 種、AR フォト、スポットの「行けた」、無人店、レシート登録、18:00 以降は便の案内 |
| `#/camera/:kind/:id` | AR フォト | カメラ映像（不可なら写真選択→SVG 風景）に人／スポットの飾り・季節モチーフ・日付と場所を重ねて合成。ドラッグ・大きさ・傾き視差。解放条件を満たさない日は撮れない |
| `#/photo/:id` | 写真 | ダウンロード、共有（Web Share API、なければ文をコピー）、印刷へ |
| `#/print/:id` | 印刷 | ハガキ判 100×148mm の印刷レイアウト（`window.print`）と同レイアウトの PNG 保存 |
| `#/memories/letters` | おもいで便 | 便の一覧（未読・30 日後にもう一度）、便の中身（コラージュ・提案 3 つ・行きたい・一言日記 140 字） |
| `#/memories/book` | ひとめぐり帖 | お店の人と関係（はじめまして／また会えたね／おなじみ、おかえり）、種と花（長押しで約束を果たす）、アルバム、これまでの旅 |
| `#/wallet` | おさいふ | ポイント、レシート登録（写真必須）、抽選と確率表、クーポン（使える／〜から／使用済み）、レシート一覧（画像は 7 日）、旧特典（参考） |
| `#/shop/:id` | 店ページ | 店の紹介、お店の人、ここで使えるクーポン（1.2 秒長押しで使用済み）、次の来訪から使えるクーポン |
| `#/settings` | 設定 | 文字の大きさ 小／中／大、配色 標準／はっきり、やさしい日本語 |
| `#/admin` | 運営の窓 | 指標、CSV 取り込み（確認→取り込み、アップロード、件数と失敗行）、店の還元率、抽選の商品（重み・在庫・額面・確率）、補填（月別・店別）、直近のレシート、変更履歴 |
| `#/present` | 発表用（DEMO_MODE=1） | 1280×720。上に 5 場面の帯、左にスマホ枠で本体（iframe）、右に場面の説明・指標・デモ操作（次の当たりの固定・初期化） |
