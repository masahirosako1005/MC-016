# 02 画面

下タブは 4 つ: **計画／マップ／思い出／クーポン**。各タブの一番上に「いまやること」カード（主ボタン 1 つ）。初回起動時に 3 枚の使い方ガイド（設定から再表示可）。ボタンは 48px 以上。
デザイン: 藍染と和紙の手紙。藍 `#1b2a44`・紙 `#fbfcfd`・差し色 山吹 `#e3a21a`（1 画面 1 箇所）。見出しは明朝（Yu Mincho）、本文はゴシック（Yu Gothic UI）。状態色は藍の濃淡で表す。

| ルート | 画面 | 主な内容 |
|---|---|---|
| `#/plan` | 計画（旅前） | いまやること → 2 ステップ（① 行きたい場所をえらぶ ② 日を決める）→ 諸島マップ（点は場所、計画の場所は山吹の輪）→ 地区・季節チップ・検索 → **場所カード 7 枚**（風景写真・紹介・**ここにいる人**・「行きたい」）→ 日を決める（その日に会えそうな人・花になる種・使えるクーポン）。下部固定バー「行きたい場所 N か所 → 日を決める」 |
| `#/place/:id` | 場所の詳細 | 風景・紹介・アクセス・「行きたい」・ここにいる人（旅中は「会えた」ボタン付き）・旅人の声（内部ダミー、件数・順位なし）・みんなの一枚 |
| `#/people/:id` | 人の詳細 | 絵・名前・役割・ひとこと・いる場所と営業時間・季節の約束 4 つ（今の季節を強調）・種／花・旅人の声・いっしょに撮った一枚。主ボタンは 1 つ（旅前「場所を行きたいに入れる」／旅中「会えた」） |
| `#/` | マップ（旅中） | いまやること → 諸島マップ（場所の点 + そこにいる人のアバター、藍の濃淡で状態）→ **行く場所**（計画の場所、カードの中に人カード: 会えた → AR フォト → レシート、花の日は長押し）→ ほかの場所（折りたたみ） |
| `#/camera/person/:id` | AR フォト | カメラ映像（不可なら写真選択→その場所の風景写真）に人の絵・季節モチーフ・日付と場所を合成。ドラッグ・大きさ・傾き視差。今日会えた人とだけ撮れる |
| `#/photo/:id` | 写真 | ダウンロード・共有（Web Share、なければ文をコピー）・印刷へ |
| `#/print/:id` | 印刷 | ハガキ判 100×148mm の印刷レイアウトと PNG 保存 |
| `#/memories/letters` | 思い出 › おもいで便 | 便の一覧（未読・30 日後にもう一度）、便の中身（会えた人・AR フォト・行った場所のコラージュ、提案 3 つ「別の季節に、また」「別のイベント」「まだ行っていない場所」→ 行きたい、一言日記 140 字） |
| `#/memories/book` | 思い出 › ひとめぐり帖 | 会った人と関係・種と花（長押し）、アルバム、これまでの旅 |
| `#/wallet` | クーポン | いまやること → クーポン（使える店のチップ）→ ポイントと抽選（確率表）→ レシート登録（店は人名つき、マップからは自動選択）と一覧（画像は 7 日） |
| `#/shop/:id` | 店ページ | 場所の写真・店の紹介・お店の人・ここで使えるクーポン（1.2 秒長押し） |
| `#/settings` | 設定 | 文字の大きさ 3 段階・配色 標準／はっきり・やさしい日本語・使い方をもう一度見る |
| `#/admin` | 運営の窓 | 指標、CSV 取り込み、店の還元率（人名併記）、抽選の商品、補填、直近レシート、変更履歴 |
| `#/present` | 発表用（DEMO_MODE=1） | 1280×720。5 場面の帯、スマホ枠の本体（iframe）、場面の説明・指標・デモ操作 |
