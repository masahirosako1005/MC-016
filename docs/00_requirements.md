# 00 要件（短縮版）

## 目的
既存の観光スタンプラリーは旅の途中しか使い道がなく、旅の後に開く理由がない。「ひとめぐり便」は、旅先で会ったお店の人との **約束（季節の種）** と **思い出（おもいで便）** を持ち帰り、季節の便りと次の旅でしか使えないクーポンで **その人に会いに戻りたくなる（再訪）** 体験を足す。旅前・旅中・旅後を 1 本で通す。

## 場面
| # | 場面 | 主な機能 |
|---|------|----------|
| ⓪ | 旅前 | しらべる（スポット・店カード、検索・チップ、SVG 諸島マップ、旅人の声）、つぎの旅（品目・予定日） |
| ① | 旅中 | きょう（今日会えそうな人の予報と理由、会えた／行けた、AR フォト、レシートでポイント） |
| ② | その夜 | おもいで便（コラージュ、一言日記 140 字、次の旅の提案 3 つ → 行きたい） |
| ③ | 30 日後 | 同じ便が再表示、行きたいを先頭に、次の季節まであと N 週間 |
| ④ | 次の季節 | 種が花に。会えた日だけ 1.2 秒長押しで約束を果たし、次の種 |

## ルール
- 季節: 春 3–5 / 夏 6–8 / 秋 9–11 / 冬 12–2。
- 会えた: 同じ日に同じ人は 1 回（DB UNIQUE）。関係 = 会えた別日数 1 / 2–3 / 4+。
- 種は人ごとに 1 つ、季節を逃しても枯れない。
- 格付け・星レビュー・ランキングは作らない。
- レシート: 写真必須、PNG/JPEG/WebP 5MB、先頭バイト判定、SHA-256 重複 409、今日のみ、金額 1〜100,000、pt = floor(金額×率)、率 1〜20% をスナップショット。画像は 7 日で削除。
- 抽選: 10pt=1 回。商品はカテゴリ単位クーポン（飲食/宿泊/体験/物販）+ はずれ。重み・在庫・額面は運営の窓で変更。確率表示。1 トランザクション。
- クーポン: 当選翌日〜当選日+1 年。同カテゴリの店で長押し使用。補填集計は運営の窓だけ。
- 旅 = 活動日の間隔 2 日以内。
