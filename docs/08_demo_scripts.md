# 08 デモ台本（1280×720、`/#/present`）

起動: `.\scripts\start.ps1 -Demo` → ブラウザで `http://127.0.0.1:8000/#/present`。
前提: 運営の窓（`/#/admin`）で一度「取り込む」を押しておくと指標に数字が入る（ダミー履歴で補われる）。発表前に右下「初期化」で主人公の履歴を旅前に戻す。初回ガイド（3 枚）が出るので、最初に見せてから「計画をはじめる」。

| 場面 | 帯のボタン | 時計 | 見せること |
|---|---|---|---|
| ⓪ 旅前 | ⓪ | 10/17(土) 10:00 | **計画**: いまやること「行きたい場所を選びましょう」。場所カード（風景写真）を眺め、「雪雫の音楽堂」カードの下に「ここにいる人: 鈴さん・秋は『音楽堂のススキ野点』」が付いていることを示す → 「行きたい」。「瑠璃凪の水鏡湖」（瑠衣さん・紅葉の湖面ラテ）も「行きたい」→ 下部バー「日を決める」→ 10/24 → 「この予定で決める」→ その日に会えそうな人（鈴さん・瑠衣さん）が出る |
| ① 旅中 | ① | 10/24(土) 10:00 | **マップ**: いまやること「雪雫の音楽堂に着いたら、鈴さんに会えたら『会えた』を押しましょう」。地図の山吹の輪が計画の場所。行く場所カードの中の鈴さん → 「鈴さんに会えた」→ はじめまして + 冬の種「雪見ぜんざい」→ 主ボタンが「いっしょに AR フォト」に変わる → 撮る（カメラ不可なら「風景で撮る」）→ 保存 → 印刷プレビュー。もどって「レシートを登録」（店が自動選択、1,200 円 × 10% = 120 pt）→ **クーポン**で抽選（右下で「次の抽選を固定: 飲食クーポン」にしておくと確実）→ クーポンは翌日から。瑠衣さんにも会えたを押す |
| ② その夜 | ② | 10/24 19:00 | 思い出タブに山吹の点。10/24 の便: 鈴さん・瑠衣さん・AR フォト・行った場所のコラージュ、提案 3 つ（別の季節に、また／別のイベント／まだ行っていない場所）→ 「行きたい」を押すと その場所が計画に入る、一言日記 |
| ③ 30 日後 | ③ | 11/23(月) 10:00 | 便に「30 日後にもう一度」。開くと行きたいが先頭、「冬まで あと 1 週間」。計画の日を決めると ④ へ |
| ④ 次の季節 | ④ | 12/1(火) 10:00 | マップ → 瑠衣さんは火曜定休（予報が効いている）。鈴さんは「会えそう」→ 会えた（また会えたね）→ カードが長押しに変わる → 1.2 秒長押し → 春の種「高原の新茶」。店ページで飲食クーポンを長押し → 使用済み → 運営の窓の補填に 500 円。瑠衣さんの花は水曜以降に（`POST /api/demo/clock {"at":"2026-12-02T10:00"}`） |

カメラが動かないとき: 「写真を選ぶ」か「風景で撮る」（その場所の写真に合成）。それでも止まったら ひとめぐり帖 のアルバムにサンプル写真 4 枚（前回の旅の風景）がある。

運営の窓で見せる: 指標（n とダミー数、3 人未満は非表示）、還元率（人名併記）の変更と履歴、商品の重み・在庫・確率、補填。

言い添えること: 「旅人の声」は内部ダミー（本番では SNS 公式 API 等に差し替え）。AR はカメラ映像 + 絵の合成で、マーカー認識はしていない。人を「選ばせない」設計 — 場所を選ぶと人が付いてきて、会ったあとに「またあの人に」が生まれる。
