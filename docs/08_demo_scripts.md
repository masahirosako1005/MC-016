# 08 デモ台本（1280×720、`/#/present`）

起動: `.\scripts\start.ps1 -Demo` → ブラウザで `http://127.0.0.1:8000/#/present`。
前提: 運営の窓（`/#/admin`）で一度「取り込む」を押しておくと指標に数字が入る（ダミー履歴で補われる）。発表前に右下「初期化」で主人公の履歴を旅前に戻す。

| 場面 | 帯のボタン | 時計 | 見せること |
|---|---|---|---|
| ⓪ 旅前 | ⓪ | 10/17(土) 10:00 | しらべる → マップ・カード・チップ。「湖畔カフェ 水鏡」の詳細 → 季節の約束「紅葉の湖面ラテ（10/20〜11/15）」と旅人の声 → つぎの旅に入れる。もう 1 件（瑠璃凪の水鏡湖）も入れ、つぎの旅で予定日 10/24 |
| ① 旅中 | ① | 10/24(土) 10:00 | きょう に計画の品目が先頭。鈴さん「会えそう（営業中）」「いま音楽堂のススキ野点の時期」、瑠衣さん「いま紅葉の湖面ラテの時期」→ 鈴さんに 会えた → はじめまして + 冬の種「雪見ぜんざい」（瑠衣さんにも会えたを押しておく）。AR フォト（カメラ不可なら「風景で撮る」）→ 保存 → 印刷プレビュー。スポット「行けた」。おさいふ → レシート登録（1,200 円 × 10% = 120 pt）→ 抽選（右下で「次の抽選を固定: 飲食クーポン」にしておくと確実）→ クーポンは翌日から |
| ② その夜 | ② | 10/24 19:00 | おもいでタブにバッジ。10/24 の便: コラージュ（瑠衣さん・水鏡湖・AR フォト）、提案 3 つ → 「行きたい」を押す（つぎの旅の候補に入る）、一言日記 |
| ③ 30 日後 | ③ | 11/23(月) 10:00 | 便に「30 日後にもう一度」。開くと行きたいが先頭、「冬まで あと 1 週間」 |
| ④ 次の季節 | ④ | 12/1(火) 10:00 | きょう → 瑠衣さんは火曜定休（予報が効いている）。鈴さんは「会えそう」→ 会えた（また会えたね）→ 花「雪見ぜんざい」→ 1.2 秒長押し → 春の種「高原の新茶」。店ページ（茶屋 雪雫）で飲食クーポンを長押し → 使用済み → 運営の窓の補填に 500 円。瑠衣さんの花は水曜以降に（`POST /api/demo/clock {"at":"2026-12-02T10:00"}`） |

カメラが動かないとき: 「写真を選ぶ」か「風景で撮る」。それでも止まったら ひとめぐり帖 のアルバムにサンプル写真 4 枚（前回の旅）がある。

運営の窓で見せる: 指標（n とダミー数、3 人未満は非表示）、還元率の変更と履歴、商品の重み・在庫・確率、補填。

備考: 「SNS で見かけた声」は内部ダミー。本番では SNS 公式 API 等に差し替える。AR はカメラ映像 + SVG 合成で、マーカー認識はしていない。
